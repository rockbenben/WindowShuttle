**창을 다른 모니터로 옮기는 일이 책상을 가로지르는 긴 드래그가 될 필요는 없습니다.** `Ctrl` 키와 마우스 오른쪽 버튼을 누른 채 원하는 모니터 방향으로 휙 넘기면, 커서 아래의 창이 이미 그 모니터로 이동해 있습니다. 화면 전체를 한꺼번에 바꾸고 싶으신가요? 단축키 한 번으로 현재 화면과 주 모니터의 모든 창이 서로 맞바뀝니다. WindowShuttle은 시스템 트레이에 상주하며 설치 없이 즉시 사용할 수 있습니다.

- **조준하지 말고 가볍게 털기(플릭).** `Ctrl` + 오른쪽 버튼을 누르고 모니터 방향으로 휙 던진 뒤 손을 뗍니다. 이미 그 화면을 향하고 있었으므로 '몇 번 모니터인가'를 먼저 계산할 필요가 없습니다. 잘못 넘겼다면? `Ctrl` + 마우스 휠 클릭으로 즉시 되돌립니다.
- **창 하나든 화면 전체든, 하나의 도구로.** 7가지 동작이 준비되어 있습니다: 현재 창 보내기, 두 화면 통째로 맞바꾸기, 모니터 연결 해제 후 흩어진 창 모두 모으기. 키보드, 마우스, 트레이 메뉴, CLI 어디서든 실행할 수 있습니다.
- **기하학적 배치는 그대로 복사되지 않고 다시 계산됩니다.** 혼합 DPI 및 다양한 해상도는 예외가 아닌 기본 환경입니다. 창 크기는 대상 모니터에 맞춰 올바르게 스케일링되며, 최대화 창은 최대화 상태를 유지하고, 최소화 창은 새 화면에서 복원되며, 스냅된 창은 절반 또는 4분면 배치를 그대로 유지합니다.
- **모니터 맵 자체가 직관적인 제어판.** 상단 패널에는 책상 위 실제 위치와 비율로 모니터가 표시됩니다. 한 카드에서 다른 카드로 창 칩을 드래그하면 즉시 이동합니다. 창을 이동할 때마다 맵이 자동 갱신되어 현재 창 위치를 항상 보여주며, 잘린 제목 위에 마우스를 올리면 전체 제목을 볼 수 있습니다. 드래그 중에는 대상 카드가 강조 표시됩니다.
- **부담 없는 완전한 오프라인 단일 파일.** 단일 포터블 실행 파일로, 설치 프로그램도 계정도 필요 없습니다. 업데이트 확인을 직접 누르거나 시작 시 확인을 켜지 않는 한 완전히 오프라인으로 작동합니다. Windows 전용입니다.

## 시스템 요구 사양

| 항목 | 지원 환경 |
|---|---|
| **OS** | Windows 10 또는 11 |
| **아키텍처** | x64 전용 (ARM64 네이티브 빌드는 제공되지 않음) |
| **.NET** | 단독 실행 빌드는 추가 설치 불필요. 경량 빌드는 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) 필요 |
| **모니터** | 2대 이상 권장. 화면 간 이동 동작은 2대 이상의 모니터가 필요하며, 모니터가 1대뿐일 때는 이동하지 않고 안내 메시지를 출력합니다 |
| **혼합 DPI / 해상도** | 완벽 지원. 픽셀 단순 복사가 아닌 대상 화면의 배율에 맞게 창 크기와 배치를 재계산합니다 |
| **관리자 권한 창** | 관리자 창을 이동하려면 WindowShuttle도 관리자 권한으로 실행되어야 합니다. 자세한 내용은 [알려진 제한 사항](#알려진-제한-사항)을 참조하세요 |

## 다운로드

**[⬇ 최신 릴리스 다운로드](https://github.com/rockbenben/WindowShuttle/releases/latest)** —— Windows x64.

- **`WindowShuttle-<version>-win-x64.zip`** —— 단독 실행 포터블 버전. .NET 런타임이 내장되어 있어 별도 설치 없이 압축 해제 후 즉시 실행할 수 있습니다. 어떤 것을 받아야 할지 모르겠다면 이 버전을 선택하세요.
- **`WindowShuttle-<version>-win-x64-needs-dotnet10.zip`** —— 경량 포터블 버전. 런타임이 제외되어 있어 시스템에 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)이 이미 설치되어 있어야 합니다. 파일 크기가 매우 작습니다.
- **`WindowShuttle.exe`** —— 위 경량 버전의 압축을 푼 단일 exe 파일입니다. 바로 실행하거나 기존 파일을 덮어써서 업데이트할 수 있습니다. 런타임이 없으면 Windows에서 다운로드를 안내합니다.

모두 동일한 단일 파일 `WindowShuttle.exe`이며 설치나 회원가입이 필요 없습니다. 유일한 차이는 시작 시의 오버헤드로, 단독 실행 버전은 매 실행 시 임시 폴더에 자체 압축을 풀기 때문에 런타임 설치형보다 시작이 약간 느립니다(주로 `list` 같은 일회성 CLI 호출에서 두드러집니다). 시스템 트레이 상주 및 단축키 반응 속도에는 전혀 차이가 없습니다.

코드 서명이 포함되어 있지 않아 최초 실행 시 Windows SmartScreen 경고가 나타날 수 있습니다. **추가 정보 → 실행**을 클릭하세요.

**오류 확인 방법.** 작업 도중 오류가 발생하면 앱이 비정상 종료되지 않고 자동으로 복구되며 알림 카드가 나타납니다. 자세한 내용은 `%APPDATA%\WindowShuttle\crash.log`에 기록됩니다. 문제가 발생하지 않았다면 이 파일은 존재하지 않습니다.

**완전 삭제 방법.** 설치 프로그램이 없으므로 평소에는 exe 파일만 삭제하면 됩니다. 단, '관리자 권한으로' 자동 시작을 켠 적이 있다면 **작업 스케줄러**에 등록됩니다. exe만 삭제하면 잘못된 작업이 시스템에 남으므로, **먼저 'Windows 시작 시 실행' 체크를 해제하세요**(작업과 레지스트리가 모두 정리됩니다). 그 후 exe와 `%APPDATA%\WindowShuttle` 폴더를 삭제하면 완전히 제거됩니다.

## 7가지 동작

7가지 동작 중 6가지는 트레이 메뉴와 CLI에서 실행할 수 있습니다. '방향으로 보내기'는 메뉴에 방향 정보가 없으므로 마우스 제스처 전용입니다. 또한 '화면 번호' 도구도 트레이 메뉴와 CLI에 마련되어 있습니다. 기본으로 2개의 단축키와 4개의 마우스 제스처가 등록되어 있습니다:

| 동작 | 키보드 단축키 | 마우스 제스처 | 동작 설명 |
|---|---|---|---|
| **화면 통째로 맞바꾸기** | `Win`+`Shift`+`X` | `Ctrl`+우클릭 왼쪽 플릭 | 현재 화면과 주 모니터의 모든 창을 맞바꿉니다. 이미 주 모니터에 있다면 직전에 맞바꿨던 모니터와 바꿉니다 |
| **맨 앞 창 맞바꾸기** | `Win`+`Shift`+`Z` | `Ctrl`+우클릭 오른쪽 플릭 | 두 모니터의 가장 앞에 있는 최상위 창만 서로 맞바꿉니다 |
| **주 모니터로 보내기** | *(미지정)* | *(미지정)* | 현재 활성 창을 주 모니터로 즉시 보냅니다 |
| **다음 모니터로 보내기** | *(미지정)* | *(미지정)* | 창을 오른쪽 모니터로 보냅니다 (가장 오른쪽에서는 가장 왼쪽 모니터로 순환) |
| **방향으로 보내기** | *(제스처 전용)* | `Ctrl`+우클릭 목표 방향 플릭 | 목표 모니터 방향으로 가볍게 밀면 커서 아래 창이 해당 모니터로 이동합니다 |
| **모두 모으기** | *(미지정)* | *(미지정)* | 보조 모니터에 남아 있는 모든 창을 주 모니터로 한 번에 회수합니다 |
| **실행 취소** | *(미지정)* | `Ctrl`+가운데 클릭 | 직전 이동 동작으로 옮겨진 모든 창을 원래 위치로 되돌립니다 |
| **화면 번호** | *(미지정)* | *(미지정)* | 각 화면 중앙에 큰 숫자를 잠시 띄워 모니터 번호(예: 1번 모니터)를 확인합니다 |

마우스 제스처는 '버튼을 누른 순간 커서 아래에 있던 창'을 대상으로 작동합니다. 반면 키보드 단축키, 트레이 메뉴, CLI는 '현재 포커스가 있는 최상위 창'을 대상으로 작동합니다.

### 마우스 제스처

마우스 제스처는 시스템 전역에서 동작하며 **창을 먼저 클릭하여 활성화할 필요가 없습니다**. 옮기고 싶은 창 위에 커서를 올리고 조합 키를 누른 채 마우스를 움직이기만 하면 됩니다.

기본 조합은 **`Ctrl` + 마우스 오른쪽 버튼**이며 설정에서 변경할 수 있습니다. 짧은 클릭은 일반 우클릭 메뉴가 열리며, 최소 데드존(24픽셀) 이상 마우스를 움직였을 때만 제스처로 판정되어 기본 우클릭 이벤트가 소비됩니다.

#### `Ctrl` + 오른쪽 버튼을 누른 채 플릭

- **대상 모니터 방향으로 털기: 방향으로 보내기.** 커서 아래 창이 해당 화면의 동일한 상대 위치로 이동합니다.
- **왼쪽으로 플릭: 화면 통째로 맞바꾸기.** 현재 화면과 주 모니터의 전체 창을 맞바꿉니다.
- **오른쪽으로 플릭: 맨 앞 창 맞바꾸기.** 양쪽 화면의 맨 앞 창만 바꿉니다.
- **가운데 버튼 1회 클릭 (드래그 불필요): 실행 취소.** 방금 옮긴 창을 원래 자리로 되돌립니다.

제스처는 데스크톱 물리 마우스 전용으로 설계되었으며, 터치패드의 멀티핑거 제스처와는 호환되지 않습니다.

## 설정

메인 창 하단 설정 표시줄 및 제목 표시줄의 '업데이트' 메뉴:

- **닫을 때 트레이로 최소화** (기본값: 켬) — 닫기 버튼을 누르면 종료되지 않고 시스템 트레이로 숨겨집니다.
- **시작 시 업데이트 확인** (기본값: 끔, 제목 표시줄의 '업데이트' 메뉴 내) — 켤 경우 매 부팅 시 GitHub에서 새 버전 유무를 1회 확인합니다. 새 버전이 있으면 다운로드 및 SHA-256 해시 검증을 거쳐 안내하며, 실행 중인 파일을 강제로 덮어쓰지 않습니다.
- **Windows 시작 시 실행** (기본값: **켬**) — 부팅 시 `--tray` 인수를 전달하여 조용히 트레이에 상주합니다.
- **관리자 권한으로** (기본값: 끔, 'Windows 시작 시 실행' 아래) — 일반 레지스트리 시작을 **작업 스케줄러 최고 권한 작업**으로 교체합니다. 체크 시 UAC 확인이 한 번 나타나며, 이후에는 매 로그인 시 UAC 창 없이 관리자 권한으로 자동 시작됩니다. 포터블 빌드에서도 완벽히 지원됩니다.

  이를 통해 UIPI 보안 장벽(관리자 창을 옮기지 못하거나, 관리자 창이 앞에 있을 때 마우스 제스처가 먹통이 되는 현상)이 완전히 해결됩니다.

- **모니터 분리 시 화면 밖 창 구조** (기본값: 켬) — 케이블이 분리되거나 절전 모드 복귀 시 화면 밖 가상 좌표에 고립된 창을 보이는 화면으로 자동 회수합니다.
- **전체 화면 앱 건너뛰기** (기본값: 켬) — 게임이나 전체 화면 동영상 재생 중 화면 맞바꾸기로 인해 화면이 튕기는 것을 방지합니다.

## 명령줄 인터페이스 (CLI)

WindowShuttle은 단일 실행 파일입니다. 상주 실행 중일 때 터미널, 스크립트, 런처 등에서 호출하면 명명된 파이프(IPC)를 통해 실행 중인 인스턴스에 명령을 전달하고 결과를 즉시 출력한 뒤 종료합니다.

상주 인스턴스가 없더라도 `WindowShuttle.exe list`와 `--smoke`는 단독으로 동작합니다.

| 명령 | 동작 설명 |
|---|---|
| `WindowShuttle.exe list` | 각 모니터의 기하학적 배치 및 창 목록을 JSON으로 출력 (읽기 전용) |
| `WindowShuttle.exe swap` | 현재 창이 있는 모니터와 주 모니터의 전체 창 맞바꾸기 |
| `WindowShuttle.exe swap-top` | 현재 모니터와 주 모니터의 맨 앞 창만 맞바꾸기 |
| `WindowShuttle.exe to-primary` | 현재 창을 주 모니터로 이동 |
| `WindowShuttle.exe gather` | 보조 모니터의 모든 창을 주 모니터로 모으기 |
| `WindowShuttle.exe to-next` | 현재 창을 다음 모니터로 이동 (오른쪽 끝에서 왼쪽으로 순환) |
| `WindowShuttle.exe to <n>` | 현재 창을 **n번째 모니터**로 이동 (n은 왼쪽부터 1, 2... 순서) |
| `WindowShuttle.exe identify` | 각 화면 중앙에 식별 번호 표시 |
| `WindowShuttle.exe undo` | 마지막 창 이동 실행 취소 |
| `WindowShuttle.exe --tray` | 트레이 모드로 백그라운드 시작 (자동 시작용) |
| `WindowShuttle.exe --help` | 도움말 요약 출력 |

명령 실행 성공 시 반환 코드는 0이며 `{"action":"to-primary","moved":1}`과 같은 JSON이 표준 출력으로 반환됩니다. 권한 부족 등으로 실패하면 반환 코드 3과 `{"error":"access_denied"}`가 반환됩니다.

## 알려진 제한 사항

- **관리자 권한 창**: 관리자 권한 없이 실행된 WindowShuttle은 작업 관리자 등 승격된 창을 이동할 수 없습니다(Windows UIPI 제한). 해결책: 설정에서 '관리자 권한으로' 자동 시작을 켜거나 앱을 관리자 권한으로 실행하세요.
- **전면 관리자 창과 제스처**: 관리자 창이 활성 상태일 때 마우스 제스처 훅이 차단됩니다. 앱 자체를 승격 실행하면 해결됩니다.
- **전체 화면 앱 제외**: 게임 등 전체 화면 창은 기본적으로 이동 대상에서 건너뜁니다. 이동을 원하시면 설정에서 비활성화할 수 있습니다.
- **응답 없는 창**: 멈춘 창은 건너뛰며 CLI 출력에 건너뛴 개수가 표시됩니다.
- **가상 데스크톱**: 다른 가상 데스크톱의 창은 의도적으로 제외됩니다. 해당 가상 데스크톱으로 먼저 전환한 뒤 이동하세요.
- **물리 좌표와 스냅 복원**: 모니터 맵은 실제 물리 픽셀 좌표를 기반으로 렌더링되며, 2x2 배치 및 세로 모니터도 정확히 지원합니다. 실행 취소 스냅샷은 `.pending` 원자적 저장을 통해 손상을 방지합니다.
- **포터블 빌드 승격 자동 시작**: 포터블 단일 파일은 사용자 쓰기 가능 폴더에서도 안전하게 작업 스케줄러에 등록할 수 있으며, 기존 따옴표 경로도 정상 인식합니다.
- **업데이트 검증**: 업데이트 확인 시 항상 SHA-256 체크섬을 검증하여 안전하게 다운로드합니다.

```bash
dotnet build WindowShuttle.sln -c Debug

```
