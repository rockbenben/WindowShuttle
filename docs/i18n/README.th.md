**การย้ายหน้าต่างไปอีกจอไม่ควรเป็นการลากเมาส์ยาวข้ามโต๊ะทำงานที่เหนื่อยล้า** กด `Ctrl` ค้างไว้พร้อมคลิกขวา แล้วสะบัดเมาส์ไปในทิศทางของจอที่ต้องการ หน้าต่างใต้เคอร์เซอร์จะย้ายไปอยู่ที่นั่นทันที ต้องการสลับทั้งจอใช่ไหม? เพียงกดปุ่มลัดเดียว หน้าต่างทั้งหมดระหว่างจอที่คุณอยู่กับจอหลักจะสลับกัน WindowShuttle ทำงานเงียบ ๆ ในซิสเต็มเทรย์และพร้อมใช้งานทันทีโดยไม่ต้องติดตั้ง

- **สะบัด ไม่ต้องเล็ง** `Ctrl` + คลิกขวา ปัดไปทางจอภาพแล้วปล่อย หากสะบัดผิด? `Ctrl` + คลิกปุ่มกลางเพื่อเลิกทำทันที
- **หน้าต่างเดียวหรือทั้งจอ** 7 ฟังก์ชันครบครัน สลับได้ทั้งทางแป้นพิมพ์ ท่าทางเมาส์ เมนูเทรย์ หรือ CLI
- **คำนวณตำแหน่งใหม่ ไม่คัดลอกแบบสุ่มสี่สุ่มห้า** รองรับจอภาพที่มี DPI และความละเอียดผสมกันอย่างสมบูรณ์แบบ
- **แผนผังจอภาพเป็นแผงควบคุม** ลากหน้าต่างข้ามการ์ดจอภาพได้อย่างง่ายดาย
- **พกพาสะดวก ออฟไลน์ 100%** ไฟล์ exe เดียว ไม่ต้องติดตั้ง ใช้งานได้บน Windows

## 7 ฟังก์ชันหลัก

| การกระทำ | ปุ่มลัด | ท่าทางเมาส์ | คำอธิบาย |
|---|---|---|---|
| **สลับทั้งจอ** | `Win`+`Shift`+`X` | `Ctrl`+คลิกขวาปัดซ้าย | สลับหน้าต่างทั้งหมดระหว่างจอภาพปัจจุบันกับจอหลัก |
| **สลับหน้าต่างหน้าสุด** | `Win`+`Shift`+`Z` | `Ctrl`+คลิกขวาปัดขวา | สลับเฉพาะหน้าต่างที่อยู่หน้าสุดของทั้งสองจอ |
| **ส่งไปจอหลัก** | *(ไม่ได้กำหนด)* | *(ไม่ได้กำหนด)* | ส่งหน้าต่างที่กำลังใช้งานไปยังจอหลัก |
| **ส่งไปจอถัดไป** | *(ไม่ได้กำหนด)* | *(ไม่ได้กำหนด)* | ส่งหน้าต่างไปยังจอถัดไปทางขวา |
| **ส่งตามทิศทาง** | *(เฉพาะท่าทาง)* | `Ctrl`+คลิกขวาสะบัดทิศ | ย้ายหน้าต่างใต้เคอร์เซอร์ไปตามทิศทางที่สะบัด |
| **รวบทั้งหมด** | *(ไม่ได้กำหนด)* | *(ไม่ได้กำหนด)* | รวบหน้าต่างทั้งหมดจากจอเสริมกลับมาที่จอหลัก |
| **เลิกทำ** | *(ไม่ได้กำหนด)* | `Ctrl`+คลิกปุ่มกลาง | คืนค่าตำแหน่งหน้าต่างก่อนการย้ายล่าสุด |
| **หมายเลขจอ** | *(ไม่ได้กำหนด)* | *(ไม่ได้กำหนด)* | แสดงตัวเลขขนาดใหญ่กึ่งกลางแต่ละจอชั่วคราว |
